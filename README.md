# SA Toolkit Pro

A gaming companion utility for Android — guides, tutorials, installation help, device compatibility, troubleshooting, tips, and reference materials.

## Live Demo

https://gta-sa-toolkit.vercel.app

A production-ready companion web app and Android shell. Built with Next.js 15, React, TypeScript, Tailwind CSS, and Framer Motion.

![SA Toolkit Pro](public/og-image.svg)

## Features

- **Game Tips & Reference** — Search, filter by category, one-click copy
- **Android Installation Wizard** — Step-by-step APK + OBB guide with FAQ
- **Device Compatibility Checker** — RAM, storage, and Android version scoring
- **Save Game Library** — Browse save categories with modern cards
- **Version Comparison** — Compare Android build profiles
- **Mission Guide** — Story mission walkthroughs and tips
- **Troubleshooting Center** — Common Android gaming fixes
- **Blog** — Tips and tutorials
- **Bilingual** — English and Arabic (RTL)
